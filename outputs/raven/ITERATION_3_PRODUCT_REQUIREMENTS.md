# RAVEN iteration 3 product requirements

This pass turns the original vision into the next measurable release gates.

## Pass 1 — evidence before appearance

- Every prompt must show exact input/output/total tokens, provider, model, cost, and total latency.
- Every memory candidate must preserve scores, exact evidence, outcome, and deterministic reason code.
- Web readiness must be verified through a callable current-data test, not a static green badge.
- The graph must identify the embedding model, dimensions, index, canonical links, inferred links, and currently used memories.

Exit: completed and verified against the running database/API.

## Pass 2 — natural local voice

- ARISE must activate RAVEN while the site is open and explicitly armed; audio must remain local.
- Voice must use the low-latency 3B path, adaptive silence detection, sentence-first synthesis, acoustic barge-in, and a deterministic interrupt control.
- The UI must show STT/model/TTS timing and token use without blocking navigation.
- Wake, threshold, chunking, local model, TTS, and current-data behavior must have repeatable automated tests.

Exit: completed for browser-active operation. OS-level always-on wake remains a separate native-client requirement.

## Pass 3 — cognitive command environment

- Dashboard must expose current state, last model turn, 24-hour tokens/cost/latency, mission state, memory admissions, and actual voice stack.
- The speaking state must drive a visible 3D reactor, not decorative fake telemetry.
- Knowledge Graph must support perspective rotation, depth zoom, 3D/2D/list modes, filtering, model node, active-memory state, inspection, and local expansion.
- Memory Vault must explain saved and rejected candidates in plain language.
- Toolchain must remain a truthful forward plan for every disconnected connector.

Exit: completed and browser-verified with no console errors.

## Iteration 4 direction

The next pass is no longer primarily visual. It must deliver a dedicated trained ARISE detector, streaming audio stages, real-room voice evaluation, checkpointed Hermes execution, and one production connector (email/calendar or Home Assistant) with read-only authorization, approval-gated writes, revoke flow, and end-to-end audit evidence.
